# Relationships

Typed knowledge-graph edges from `data/relationships.json`.

Supported relations:

| Relation | Example |
|---|---|
| `belongs_to` | practice → tradition |
| `related_to` | practice → concept |
| `described_in` | practice → text |
| `translated_as` | concept → term |
| `associated_with` | person → tradition |
| `concerns` | experience → concept |
| `derived_from` | pattern → experience |
| `investigates` | research → pattern |
| `discusses` | text → concept |
