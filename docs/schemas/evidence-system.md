# Evidence System

Every claim carries exactly one class:

| Class | Meaning |
|---|---|
| `PRIMARY SOURCE` | Classical text, original document |
| `HISTORICAL EVIDENCE` | Verifiable historical record |
| `SCHOLARLY INTERPRETATION` | Published scholarship |
| `TRADITIONAL / LINEAGE INTERPRETATION` | What the tradition says |
| `MODERN RESEARCH` | Published scientific study |
| `PRACTITIONER EXPERIENCE` | Anonymized personal report |
| `CONTEMPORARY COMMUNITY OBSERVATION` | Observed community discourse |
| `EDITORIAL SYNTHESIS` | Our own analysis, clearly labeled |
| `UNCERTAIN` | Insufficient evidence — preserved as uncertainty |

These classes are never mixed.
